Animal Crossing Map Viewer

The purpose of this map viewer is to see where trees can grow in your town.

The map viewer can reveal which tiles in an acre are good to grow, taking objects such as existing trees, rocks, villager houses, or other structures into consideration.

Upload Save

Upload your Doubutsu no Mori(+/e+) or Animal Crossing save file in the .GCI format. Your save data is never sent to a server! Data is only stored in browser memory.
